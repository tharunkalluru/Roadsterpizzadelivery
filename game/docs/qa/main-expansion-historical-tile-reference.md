```sh
node scripts/export-historical-tile-road-model.mjs \
  --historical-manifest HISTORICAL_WORLD_MANIFEST.json \
  --ids CHANGED_TILE_ROAD_IDS.json \
  --include-core-ids CHANGED_CORE_ROAD_IDS.json \
  --context-ids FIXED_NEARBY_TILE_IDS.json \
  --metadata-parent ORIGINAL_HISTORICAL_TILE_REFERENCE.json \
  --output NEW_HISTORICAL_TILE_REFERENCE.json
```

Each ID input is a unique string array or `{ "ids": [...] }`; the core/context selectors are optional. Fixed context selectors seed explicit nearby crossing coverage without conflating them with mutable requested streets. The final core selector makes the baseline literal historical triangles throughout the complete changed footprint. Core IDs missing a raw tile copy or rendered pavement remain separately classified. Large generated references stay outside the production archive and can be reproduced from the committed source, raw packs and exact historical commit. Their hashes and the small audit receipts identify which outputs were tested. Provenance maps are sorted and dependency/source locks checked before and after generation.

The metadata replay reads `paintLift` and the unpainted four-vertex `roadQuad` directly from every matched historical `Surface`, before duplicate removal. `triangles[].actualSurface` also binds the literal road, segment, raw parent road, legacy source arc and centreline endpoints. Neither the road class nor `cap` determines the film: clipped road strips also use triangular quads, and mixed-class junction caps can use another incident road's larger film. Missing or non-finite literal metadata rejects generation.

`--metadata-parent` binds an existing complete reference. The replay compares every legacy field, including triangle order/Float32 coordinates, copies and their original emitted hashes, footprints, derived fragments, ROI and all historical source hashes. The output retains the parent's original provenance, adds `sourceHistoricalTileModelSHA256`, and records the new exporter/helper/input/source checks under `metadataExport`. Copy hashes continue to describe the unchanged legacy records; `metadataExport.metadataSHA256` binds the additive metadata. Equivalent owner/context origins deduplicate normally. A shared old token with a differing film, structural quad or source branch is retained in `actualSurfaceBindings`, listed as unresolved and returns a failing exit status. No structural first-winner policy is permitted.
