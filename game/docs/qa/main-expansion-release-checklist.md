## Publication transaction

All feature gates above describe the reviewed source and observed scopes. After this checklist is committed, the Site workflow must build from that clean commit, push/package the exact state and save/deploy it with the existing audience. The returned Site version/deployment and live `build-info.json` are the publication evidence; this pre-publication source document does not invent their future IDs. The production archive excludes QA snapshots, raw authoring drafts and source documentation. The retired Version21 project is not a release target.

## Performance boundary

The normal-pickup development session recorded about seventeen minutes of focused desktop observer callbacks near 60 callbacks/s. It was not a controlled GPU-completed-frame benchmark or a final-build phone measurement. Android emulation can establish compatibility and control/layout behavior only. No physical-phone 60/90/120 FPS, heating or battery-life result is claimed without a real hardware session and measurements.
