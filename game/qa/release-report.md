## 2. What is playable

A browser game (Three.js) on the Uppal-Tarnaka package `hyd-uppal-tarnaka` v1.0.0: select a mission, drive the OSM-derived street graph with traffic, take off and fly using one shared flight allocation per contract (default 25 s, 20/25/30 s variants, no regeneration), land, stop at the delivery entrance, deliver, see results, retry or exit. 10 delivery locations; 12 instantiated mission templates (practice plus 11), including a return mission, multi-stop and a full-corridor mission. Unit and browser tests exercise these (section 5). Red and Green corridors are shown as planned scope, not playable.
