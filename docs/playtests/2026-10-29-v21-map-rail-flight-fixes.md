# Version 21 urgent map, railway and flight repairs

Baseline: `bd7313d6d20cb3f6a448bedb2e52bccd269b1bba`, the actual active Version 21 client, restored in descendant commit `9882a43`. This patch does not import the rejected Next Lab timing, flight-controller, camera-presentation, pooling or traffic optimizations. Public Site identity and audience are preserved.

## Changes and causes

1. **Full map:** first open previously waited for fetch, gzip decode, JSON parse and paths for the entire city. A dedicated worker now downloads/decodes/indexes; the shell and local core roads paint immediately. Exact Float64 map coordinates and source drawing order are retained. Visible minor-road cells prepare within bounded slices; unused path cache is bounded. Work pauses when closed, cached paths survive reopening, aborted requests cannot reopen the map, and failed downloads retry on explicit open. Worker-bootstrap incompatibility retains the functional main-thread fallback, which may still block on its initial JSON parse.
2. **Railways:** trains previously selected random directions on shared source ways, despite physically parallel mapped tracks. Mapped track pairs now receive opposite, persistent flows; straightest mutual continuation avoids station-siding diversion. Shared-way reservations and swept coach checks prevent spawn overlaps and yield at crossings. Source geometry, bridge elevations and train roof carry remain unchanged. Joined runs cache only while source track identities remain unchanged.
3. **Flight guidance:** accepted pickup/customer targets now have an opaque, compact car-relative direction arrow, direct horizontal distance, steering hint and nearby landing hint. Pickup is orange; customer is teal. It follows car heading independently of free-look camera angle, smooths across bearing wrap, and hides on the ground, menus, map, blocking tutorials, invalid/no accepted jobs or insufficient layout room. Ground routing remains unchanged.
4. **Hover camera:** altitude previously triggered automatic recentering every frame and flight pitch ignored vertical drag. Hover now preserves the selected yaw, pitch and zoom after release; moving flight rejoins chase view along the shortest arc. A single pointer owns the gesture and cancellation/menu/reset releases capture. Clicking the scene returns keyboard focus, so Space does not reactivate the previous minimap button. Original frame timing, ground framing, field of view and chase damping are retained.

## Limits

Browser checks complement rather than replace actual-source collision and input fixtures.
