# Intended-road height during traffic maneuvers

Traffic previously sampled a curved horizontal path while interpolating only the two endpoint heights. On a road whose slope changes inside that path, the vehicle could float above or sink into the asphalt even after its ordinary graph position was corrected.

`TrafficCurve` now accepts an optional Y-only support lookup before the production planner runs its existing clearance checks. Bend, lane-change, U-turn, junction and scheduled-bus maneuvers supply their actual directed road spans. The lookup converts those spans to local source-segment windows, checks finite road triangles, and selects support nearest the existing height guide within the existing 1.25 m clearance tolerance. It cannot select an unrelated road or a distant looping source segment. Ambiguous or missing support retains the old chord and the existing path-clearance/retry behavior; it does not invent connecting pavement.

The horizontal path, length table, turning radius, heading, speed limits and progress clock are unchanged. The offline/no-city path remains unchanged. Flat-road sampling is exactly equal to the prior curve. The lookup is also used by ordinary swept traffic movement and its collision samples, so the displayed root and the path checks use the same corrected Y.

Work is local and bounded: nine surface cells per query, at most64 intended spans,32 cached cells,512 source surfaces and256 owned surfaces per cell. The bus planner has a48-piece/120 m horizon. World appends invalidate by array length; unload/replacement invalidates by bucket identity. No copied road geometry, city scan, nearest-deck search or per-query temporary arrays are introduced. String cell keys follow the existing world-grid representation.

Six focused controls pass, including actual Float32 asphalt where the old chord differs by over25 cm and the new sampled root stays within1 mm, directed reverse/U-turn windows, live tile lifecycle, ambiguous/foreign surfaces, finite edges and cache limits. A real `Traffic.advance` fixture carries the corrected root through120 swept updates without changing its speed. Independent review adds six adversarial controls, including a three-edge bus route with reverse spans. All twelve curve controls, seven posture/collision groups and typecheck pass; a subsequent broader69-test traffic run also passes after the block-cache change. The two-tile current-model budget census supports1,005/1,005 queries without fallback. See `main-expansion-traffic-curve-support-independent.md`; final nonlinear full-vehicle/city driving and final-profile density remain separate gates.

`evidence/reported-roads/traffic-curve-support-cpu.json` records eight paired desktop Node samples,55,000 queries each. Median added cost is0.01992 ms per55 warmed curve samples; median cold sampler plus first lookup is0.538 microseconds on this Mac. Its imported source hashes were unchanged. This measures this bounded CPU lookup only, not full Traffic.update, phone performance, GPU frames, heating or battery life.
