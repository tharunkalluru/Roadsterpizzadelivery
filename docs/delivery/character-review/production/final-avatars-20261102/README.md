# Exact avatar source and review archive

This folder preserves the selected Odela v7 and Salaar v9 native authoring scenes, exact contracts, source provenance, official photographic references, and the independently inspected model views. `curation-manifest.json` fingerprints every copy and maps it to the original local authoring path. Copies are byte-identical; no rejected or intermediate file was deleted.

The large local `missing-avatars-20261102` authoring directory is excluded from Git. Its Blender iterations, rejected model exports and working previews remain on the owner’s computer. Only separately approved public GLB/rig files and independent registry records may activate a production character. These source files and isolated model images do not constitute actual story-scene approval.

The two native Blender files retain the editable modeled assets. Original generation/reconstruction metadata and exact rig contracts are in each character’s `source` directory. Refer to the independent round-three/round-four reports and the subsequent actual scene review for the precise scope of each verdict.
