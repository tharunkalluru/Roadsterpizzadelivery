This supersedes the [8de5 memory-cleanup candidate](../memory-cleanups-2026-11-01/README.md), whose [native run stopped before release](../final-8de5-memory-soak-2026-11-01/candidate-revision-reason.json) at **1,242,142 active ms (20.7024 minutes)**. Source review identified a shader-program lifetime churn risk from disposing the PMREM sky material after every refresh. The observed 595 ms maximum interval is not causally attributed to that source risk. Its v8 software results remain valid only for that older snapshot.

The refined `EnvironmentSkyCapture` keeps **one private capture scene, sky geometry and ShaderMaterial per Engine**. Each normal environment refresh copies vectors and scalar values into the existing uniform objects, sets `uniformsNeedUpdate`, and reuses the same material. It does not mark the material for recompilation or dispose it on every clock update. PMREM target replacement still retires only the superseded target after successful capture; failure preserves the previous environment and permits retry.

Explicit owner teardown disposes the private geometry/material once. Engine retains the owner across persisted page-hide/bfcache events, releases it on non-persisted page hide, and invalidates the environment key after context restoration for the next normal refresh. The visible sky, clock cadence, global exposure, camera, actors and people counts are unchanged. Shared pedestrian lease cleanup from the earlier candidate is retained, including the bounded unused cache and live-borrower protection.

Five environment-owner regressions cover stable object/uniform identity, refresh/retry upload flags, replacement/failure ownership, repeated capture cleanup, and owner/page/context lifecycle. Five pedestrian ownership checks are also included in the 764-test total. These Node fixtures use a substituted PMREM service; they do **not** establish real GPU program counts, GPU bytes, presented FPS, emulator world rendering, phone performance, heat or battery endurance. Actual native comparison remains in progress.
