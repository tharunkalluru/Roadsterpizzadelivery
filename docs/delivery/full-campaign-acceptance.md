## Observer limits and protections

- Observations sample four times per second. Local-set lookup never scans the complete city. Evidence buffers are bounded, and full JSON is copied only when explicitly exported.
- `placementRevision` distinguishes normal initial spawn from later relocation. Staging is explicitly marked even if it happens between samples.
- Missing independent art cannot be approved through this tool. Animation observations identify a real advancing authored clip on either a released character or an explicitly labelled local comparison candidate. Local comparison metadata remains unpublished and cannot satisfy independent release approval; a moving group or function stub cannot satisfy authored-motion evidence.
- A full campaign uses all IDs from the current content list. An added level without a matching acceptance scenario remains unverified.
- Device identity, real-phone performance, long-session stability, heat and battery endurance require separate physical-device evidence. This tool never asserts physical hardware verification.
